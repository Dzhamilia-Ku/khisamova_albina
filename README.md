# Handoff: Сайт-визитка Альбины Хисамовой (визажист/преподаватель)

**Статус: ФИНАЛЬНАЯ согласованная версия.** Все значения ниже — не черновик, а то, что клиент лично проверил и утвердил после нескольких раундов правок. Реализуйте 1:1, включая мобильную версию — расхождения между дизайном и продакшеном (как случилось с прошлой выгрузкой) недопустимы.

## Overview
Одностраничный сайт-визитка (link-in-bio) для визажиста и преподавателя Альбины Хисамовой. Разделы: hero, «Обо мне», услуги, курс «Сам себе визажист» с подарком-лид-магнитом, портфолио, контакты. Основная цель — представить услуги и курсы, вести трафик в Instagram Direct.

## Файлы
- **`site-static.html` — используйте этот файл.** Полностью самостоятельный HTML/CSS, открывается в любом браузере без зависимостей. Верстайте по нему буквально: разметка, инлайн-стили и медиа-запросы внутри уже реализуют утверждённый дизайн для десктопа И мобильного.
- `assets/` — все изображения, включая уже предобрезанные (см. ниже).

## Дизайн-токены

**Цвета (oklch):** фон `oklch(96.5% 0.012 75)`, текст/акцент тёмный `oklch(30% 0.045 40)`, акцент бледно-розово-лиловый `oklch(58% 0.04 350)` (лейблы), светлый текст на фото `oklch(92–98% 0.008–0.015 75)`.

**Типографика:** заголовки — Cormorant Garamond (serif) вес 500; текст — Manrope; эйбрау-лейблы 13px uppercase letter-spacing 0.14em.

**Радиусы:** 2px везде (острый editorial-стиль, не скруглять сильнее).

## КРИТИЧНО: hero-фото — `assets/hero-final.jpg`

Это готовый, ПРЕДОБРЕЗАННЫЙ файл — рамка (глаза, брови, подбородок, положение относительно текста) уже зашита в сами пиксели изображения. Раньше кроп держался на процентных `object-position`/`transform` значениях, которые давали РАЗНЫЙ результат в зависимости от ширины окна браузера — из-за этого на проде подбородок оказался обрезан, хотя в дизайне всё было верно.

**Используйте только:**
```css
object-fit: cover;
object-position: center;
```
Никаких других значений, `transform`, `scale`, `translate` на этом изображении быть не должно — ни на десктопе, ни на мобильном. Не подставляйте архивный оригинал `hero-fullpage.jpg` — он оставлен в assets только для истории, в разметке не используется.

## Разделы (Screens)

### 1. Header (sticky nav)
Sticky, полупрозрачный фон с blur, нижняя граница 1px. Слева — имя, справа — ссылки-якоря на десктопе (≥760px), гамбургер-меню на мобильном (<760px) с выпадающим списком ссылок.

### 2. Hero
- Full-bleed `hero-final.jpg` на весь экран (92vh), `object-fit:cover; object-position:center` (см. критичный блок выше)
- Два градиента поверх: вертикальный (тёмный снизу) + горизонтальный (тёмный слева) для читаемости текста
- Эйбрау «Визажист и преподаватель · Казань», H1 с именем, описание, CTA «Написать в Instagram» (единственный CTA секции)

### 3. Обо мне — **десктоп и мобильный оформлены ПО-РАЗНОМУ намеренно**
Это не два случайных состояния — это единая продуманная композиция для каждого форм-фактора:

- **Десктоп (≥760px):** full-bleed фото-фон (78vh), горизонтальный градиент слева (тёмный) → справа (прозрачный), текст оверлеем слева, лицо модели видно справа.
- **Мобильный (<760px):** та же логика "текст поверх фото", но перестроенная под вертикальный формат — секция выше (86vh), выравнивание текста к низу, **вертикальный** градиент (тёмный снизу вверх, для читаемости текста внизу), `object-position` фото меняется на `62% 15%` (не берите десктопный `130% 20%` — на мобильном это другое значение). Текст-блок ПОВЕРХ фото внизу секции — это финальное решение клиента (было: раздельный стек фото/текст — не подходит, отклонено).

Все конкретные CSS-значения для мобильного — в `<style>` внутри `site-static.html`, блок `@media (max-width: 759px)`, селекторы `#about.about-section`, `#about .about-photo img`, `#about .about-gradient`, `#about .about-text` — переносите один в один.

### 4. Услуги («Какой образ вам нужен?»)
3-колоночная сетка (десктоп) / 1 колонка (мобильный). 5 карточек: Свадебный, Вечерний, Съёмочный, «Сам себе визажист» (курс), Личный бренд (курс) — текст в файле дословный, не перефразировать.

### 5. Курс «Сам себе визажист»
2-колоночная сетка (десктоп) / 1 колонка (мобильный): ч/б фото + текст с 3 пунктами (SVG-чекмарки), CTA «Записаться на курс», отдельный баннер-подарок «бесплатный мини-курс».

### 6. Портфолио («Работы»)
Асимметричная bento-сетка (десктоп): одно большое фото (2×2 слева) + 5 меньших (2 сверху справа, 3 в ряд снизу). На мобильном — схлопывается в 1 колонку, аспект 4:5 на карточку. Обратите внимание: у фото `work-navy-vest.jpg` есть `transform: scale(2.5) translateX(20px) translateY(-10px)` — это намеренный зум на лицо, оставить как есть.

### 7. Контакты
Центрированный блок, заголовок + один CTA `@khisamova_albina` → Instagram.

### Footer
Копирайт + город.

- Все CTA ведут на `https://www.instagram.com/khisamova_albina/`

## Responsive breakpoint
759px / 760px — единственная точка перелома. Все мобильные переопределения см. `@media (max-width: 759px)` в `site-static.html`.
