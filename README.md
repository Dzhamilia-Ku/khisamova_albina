# Handoff: Сайт-визитка Альбины Хисамовой (визажист/преподаватель)

## Overview
Одностраничный сайт-визитка (link-in-bio) для визажиста и преподавателя Альбины Хисамовой. Разделы: hero, «Обо мне», услуги, курс «Сам себе визажист» с подарком-лид-магнитом, портфолио, контакты. Основная цель — представить услуги и курсы, вести трафик в Instagram Direct.

## About the Design Files
Файлы в этом пакете — **дизайн-референс, сделанный в HTML** (единый файл `site.html`), а не production-код. Задача разработчика — воссоздать этот дизайн в целевом стеке проекта (React/Vue/статический сайт/конструктор — по решению команды), используя инлайн-стили как точный референс значений (цвета, отступы, размеры шрифтов), а не копировать HTML напрямую.

## Fidelity
**Высокая (hifi)** — финальные цвета, типографика, отступы и композиция каждого блока. Разработчик должен воссоздать вёрстку максимально точно, ориентируясь на приведённые значения.

## Design Tokens

**Цвета (oklch):**
- Фон (светло-бежевый): `oklch(96.5% 0.012 75)`
- Текст/акцент тёмный (шоколадный): `oklch(30% 0.045 40)`
- Акцент бледно-розово-лиловый: `oklch(58% 0.04 350)` (лейблы), `oklch(78–93% 0.03 350)` (светлые версии для фонов/линий)
- Светлый текст на тёмном/фото: `oklch(92–98% 0.008–0.015 75)`

**Типографика:**
- Заголовки: Cormorant Garamond (серif), вес 500, размеры от clamp(26px,3vw,34px) до clamp(44px,7vw,80px) в зависимости от уровня
- Основной текст: Manrope (sans), 15–18px, line-height 1.6–1.75
- Эйбрау-лейблы: 13px, uppercase, letter-spacing 0.14em

**Отступы секций:** clamp(32px, 5vw, 56px) — clamp(48px, 8vw, 88px) вертикально, контейнер max-width 1200px с боковым padding clamp(20px,5vw,40px)

**Радиусы:** 2px (минимальное скругление на фото и кнопках — острый, editorial стиль)

## Screens / Sections

### 1. Header (sticky nav)
- Sticky, полупрозрачный фон с blur, нижняя граница 1px
- Слева: имя (Cormorant Garamond, 22px), справа: ссылки-якоря (Обо мне / Услуги / Работы / Контакты)
- Мобильная версия: гамбургер-меню (кастомная SVG-иконка, 3 линии), выпадающий список ссылок

### 2. Hero
- Full-bleed фото на весь экран (92vh), object-position подобран так, чтобы лицо было в кадре
- Градиент оверлей (сверху прозрачный → снизу тёмный, oklch(20% 0.03 40)) для читаемости текста
- Эйбрау: «Практикующий визажист и преподаватель · Казань»
- H1: имя, крупный serif
- Параграф-описание + CTA-кнопка «Написать в Instagram» (единственный CTA секции)

### 3. Обо мне
- Full-bleed фото-фон (78vh, обрезана высота на ~38px для устранения лишнего кадра снизу/пальцев в кадре)
- Горизонтальный градиент слева (тёмный) → справа (прозрачный), текст слева, лицо модели справа
- Текст: эйбрау «Обо мне», заголовок, 3 параграфа (о работе, 11 лет преподавания, ссылка на Instagram)

### 4. Услуги («Какой образ вам нужен?»)
- 3-колоночная сетка (на мобильных — 1 колонка)
- Карточки услуг: title (Cormorant Garamond 26px), описание, note (формат/тип)
- 5 позиций: Свадебный, Вечерний, Съёмочный, «Сам себе визажист» (курс), Личный бренд (курс)

### 5. Курс «Сам себе визажист» (продающий блок)
- 2-колоночная сетка: фото (ч/б) слева, текст справа
- Заголовок, продающее описание, 3 пункта с чек-иконками (SVG, stroke, акцентный цвет)
- CTA «Записаться на курс» + отдельный баннер-подарок: «Подарок: бесплатный мини-курс по макияжу» с CTA «Получить →»

### 6. Портфолио («Работы»)
- Асимметричная bento-сетка: одно большое фото (2×2) + 2 меньших фото справа
- object-fit: cover на всех фото

### 7. Контакты
- Центрированный блок, заголовок + единственный CTA «@khisamova_albina» → Instagram

### Footer
- Копирайт + город, минимальный

## Interactions & Behavior
- Плавный скролл по якорным ссылкам (`scroll-behavior: smooth`)
- Мобильное меню: toggle состояние (open/close), кнопка-гамбургер
- Hover на ссылках: цвет меняется на бледно-розово-лиловый акцент
- Все внешние CTA ведут на `https://www.instagram.com/khisamova_albina/`

## Responsive
- Breakpoint 759px: сетки переходят в 1 колонку, десктоп-навигация скрывается, показывается гамбургер
- Изображения с изменяемым object-position для сохранения композиции на мобильных

## Assets
Все фото — реальные фотографии, предоставленные клиентом (портретные/рабочие снимки визажиста и её работ). Список файлов — в папке `assets/` этого пакета, использованы как full-bleed фоны и в сетке портфолио.

## Files
- **`site-static.html` — используйте этот файл.** Полностью самостоятельный HTML/CSS, открывается в любом браузере без зависимостей, ничего не нужно устанавливать.
- `site.html` — экспорт из внутреннего дизайн-инструмента (Design Component). У него нет `support.js`-раннтайма вовне инструмента — открывать напрямую не нужно, только для справки по истории версий.
- `assets/` — все использованные изображения, в разрешении оригинала
